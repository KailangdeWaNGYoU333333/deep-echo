Deep Echo
从随机噪声中进化出数学定理。

1940 年，英国人在布莱切利庄园造了一台叫“炸弹机”的机器。它不思考，不理解战争，只是疯狂地穷举 Enigma 密码机的每一个转子位置，直到密文变成有意义的德文单词。八十年后，比特币矿机重复着同样的逻辑——不思考，不理解，只是穷举 nonce，直到哈希值满足条件。

这两个故事有一个共同的词根：暴力证明。不是推导出来的真理，是撞出来的真理。

Deep Echo 把这个逻辑带进了数学证明。它把数学定理看作基因，用 Lean 4 编译器作为自然选择——生成、验证、筛选、进化。从随机噪声开始，一代代编织出越来越接近真理的证明。不需要人类直觉，不需要数学天赋，只需要算力和耐心。

数学家一直相信，一个证明被写出来，是因为有人类心灵理解了问题。但万一证明不是必须被理解的——万一它可以像生命一样，被进化出来呢？

快速开始
bash
pip install -r requirements.txt
python oracle.py
输入任何数学猜想，系统自动搜索或进化证明。完全本地运行，不依赖云端 API。

工作原理
生成：随机生成证明语法树（支持量词、蕴含、模运算等）

验证：Lean 4 编译器严格检查，编译通过满分，失败按错误类型给部分分

筛选：精英保留、交叉变异、定期灭绝、大模型顾问建议

进化：种群 200，每 5 代调用本地模型审视最佳个体，提出改进方向

运行要求
Python 3.12+ / Lean 4 / GPU 显存 8GB+（推荐）
